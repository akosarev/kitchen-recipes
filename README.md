# kitchen-recipes

Recipes for Kitchen Master, an offline cooking app for iPhone and iPad, as plain JSON.
The app itself is published here too: https://akosarev.github.io/kitchen-recipes/

## Layout

| Path | What |
|---|---|
| `recipes/index.json` | List of recipes, in display order. |
| `recipes/<id>.json` | One recipe per file. The file name is the recipe id. |
| `scripts/validate.mjs` | Checks every recipe file (Node 20+, no dependencies). |
| `.github/workflows/pages.yml` | Publishes the site: the app from branch `app` plus `recipes/` from `main`. |
| `.github/workflows/validate.yml` | Runs the checks on pull requests and feature branches. |

Branch `app` is generated by the app's CI and overwritten on every deploy. Do not edit it by hand.

## Format

`recipes/index.json`:

```json
{
  "version": 1,
  "recipes": [
    { "id": "mie-udang", "title": "Mie Goreng Udang", "file": "mie-udang.json" }
  ]
}
```

- `version` is the format version, currently `1`.
- `id` is lowercase words joined by `-`. `file` is always `<id>.json`. `title` matches the recipe's title.

`recipes/<id>.json` (format version 1):

| Field | Type | Meaning |
|---|---|---|
| `id` | string | Same as the file name and the index entry. |
| `title`, `sub` | string | Name and one-line description. |
| `time` | string | Total time as shown, e.g. `"about 25 min"`. |
| `base` | integer | Servings the quantities are written for. |
| `groups` | array | Ingredient groups: `{ "title", "items": [{ "k", "q", "u", "n" }] }`. |
| `groups[].items[].k` | string | Ingredient key, unique within the recipe. |
| `groups[].items[].q` | number | Quantity for `base` servings. |
| `groups[].items[].u` | string | Unit: `g`, `ml`, `tbsp`, `tsp`, `cloves`, or `""` for a count. |
| `groups[].items[].n` | string | Ingredient name as shown. |
| `phases` | array | Cooking phases: `{ "t", "time", "steps": [{ "t", "sub"?, "timer"? }] }`. |
| `phases[].steps[].t` | string | Step text. `{k}` is replaced with the scaled amount of ingredient `k`. |
| `phases[].steps[].sub` | string[] | Optional sub-steps, same placeholders. |
| `phases[].steps[].timer` | integer | Optional timer length in seconds. |
| `tip` | string | Closing tip. |

Files are UTF-8 (no BOM), pretty-printed with 2-space indentation, with a trailing newline.

## Check

```sh
node scripts/validate.mjs
```

It fails when a file does not parse, an id does not match its file name or the index, a file is
missing from the index, a field has the wrong type, or a `{k}` placeholder names no ingredient.
